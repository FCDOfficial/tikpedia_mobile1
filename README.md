# TIKpedia Mobile

Aplikasi media pembelajaran interaktif TIK berbasis Flutter.

Versi ini dibangun dari template Flutter kosong berdasarkan mockup TIKpedia dan requirement proyek: materi, game edukasi, kuis, XP/reward, progress, dan profil. Backend PostgreSQL + FastAPI sudah disiapkan di folder `backend/`.

Lihat `SETUP_TIKPEDIA.md` untuk langkah menjalankan aplikasi dan mengaktifkan database.
